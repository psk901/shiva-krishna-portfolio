# Shiva Krishna Pallety — Portfolio

Personal portfolio for GitHub user [psk901](https://github.com/psk901). Built with plain HTML, CSS and JavaScript; no build command or paid service required.

## Deploy free on Netlify
1. Sign in at https://app.netlify.com/ with GitHub.
2. Choose **Add new site → Import an existing project**.
3. Select this repository.
4. Leave build command blank and set publish directory to `.`.
5. Deploy.

## Google SEO
After Netlify assigns your site URL, replace `YOUR-NETLIFY-SITE` in `index.html` (canonical URL and JSON-LD), `robots.txt` and `sitemap.xml` with your exact Netlify subdomain. Add the URL-prefix property in https://search.google.com/search-console/, verify ownership, submit `/sitemap.xml`, then request indexing for the homepage. Google controls indexing and ranking; neither is guaranteed or immediate.
